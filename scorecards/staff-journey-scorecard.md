# Staff and advisor journey scorecard

Use the same fictional inn report as the [owner journey](owner-journey-scorecard.md). Begin with an authorized staff account, a user without staff access, and a report that is still being prepared. Complete the staff review before the owner requests a consultation. Staff accounts cannot self-register: provision them at boot with `STAFF_EMAILS` and `STAFF_PASSWORD`, and note that the roster skips an email that already belongs to an owner account.

See the [project overview](../PROJECT.md) for staff responsibilities and report access. Use the result labels in the [MVP success criteria](mvp-success-criteria-and-agent-scorecards.md). Record whether notifications and report generation used live services or a labeled substitute.

| Check | MVP criterion | Pass when | Result | Evidence |
|---|---|---|---|---|
| S1. Receive the ready notification | 6 | Designated staff are notified when the completed report is ready. The notification corresponds to the correct business and report. | | |
| S2. Review before a request | 6 | Designated staff can open the completed report as soon as it is ready, before the owner requests follow-up. They see the workflow diagrams, estimates and recommendations for the same report the owner receives. | | |
| S3. Check staff access | 6 | A signed-out visitor or a user without staff access cannot open the staff view or use its actions. The owner can still access their own report through the owner view. A staff account also cannot take the owner's interview path: the interview page shows a staff notice instead. | | |
| S4. Pick up a consultation request | 6 | After the owner requests a consultation, designated staff can see the request, the report it belongs to, and the consultation state in the staff report list. | | |
| S5. Walk through the recommendations | 6, 7 | In the demo, the advisor uses the report to explain the findings and discuss questions or changes with the owner. The owner can choose a next step. The advisor may introduce a suitable local implementation partner where useful. | | |

For the handoff, record the account roles used, the ready notification and report access checks, and how the advisor found the consultation request. The advisor walkthrough demonstrates the human follow-up. Implementation remains a separate engagement.
